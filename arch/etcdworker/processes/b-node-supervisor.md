# B. NodeSupervisor (наблюдение, repair, orphan-cleanup)

Уровень 4. Наблюдение живости managed-узлов, восстановление окружения и
снос осиротевших docker-объектов. Функция —
[03-node-supervision.md](../03-node-supervision.md); модель —
[01-placement.md](../01-placement.md); принципы —
[17-synchronization-principles.md](../../17-synchronization-principles.md).

Исполняется в тике доводки под лидер-клэймом: наблюдение — ДО
`MembershipProcess` ([A](a-membership.md)), repair и orphan-cleanup — после
него. Фазы журнала: `orphan-cleanup`.

```
B1 наблюдение (Observe): для каждого managed-члена —
   гейт пробы HealthIntervalSec по последней пробе узла (гейт закрыт —
   данных нет, метка проблемы не ставится);
   health-проба /v3/maintenance/status по client-порту portalloc;
   успех: метка проблемы сбрасывается; state UNREACHABLE → RUNNING;
   проблема (unstarted ИЛИ молчание): метка ПЕРВОГО наблюдения
   запоминается; docker-инспекция — отсутствует ли окружение;
   молчание дольше NodeDeadSec и состояние RUNNING/UNREACHABLE →
   UNREACHABLE (деструктива нет, S7); факт проблемы (член, since,
   environmentMissing) отдаётся в A3; между узлами — прогресс-отметка
   цикла (поллинг-инвариант долгих фаз)
B2 repair (Repair): ОДИН шаг за тик — только узлы RUNNING/UNREACHABLE с
   членом и закреплённым портом; состав перечитывается на момент решения;
   контейнер отсутствует/не работает → state=PROVISIONING → пересоздание с
   закреплённым портом и сохранённым volume → state=RUNNING;
   client-порт контейнера разошёлся с закреплением → снос контейнера
   (volume жив) → пересоздание с портом portalloc
B3 orphan-cleanup: объекты etcdw-node-* (label `etcdworker`) без члена в
   составе → снос контейнера и volume + освобождение portalloc;
   состав и объекты перечитываются на момент решения (снимок начала тика
   устаревает: свежедобавленный член иначе сносился бы как сирота);
   состав нечитаем — мусорщик молчит (снос без факта небезопасен)
```

Слепая docker-инспекция — ошибка тика без действий; слепая health-проба —
факта нет. Тома живого члена неприкосновенны: снос — только по доказанному
сиротству (нет члена в составе).
