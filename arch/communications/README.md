# Межкомпонентные коммуникации и границы оркестрации

Уровень 2. Канон того, как компоненты системы общаются друг с другом и что
им позволено в отношении контейнерной оркестрации. Распространяется на все
продуктовые компоненты: панель, воркеры (PgWorker/KafkaWorker/S3Worker/
ValkeyWorker/EtcdWorker), контейнеры нод, джобов и агентов. Новые компоненты
и каналы проектируются по этому документу (arch-first). Операции
оркестрации сверх разрешённых — только по явному апруву владельца проекта,
до которого не реализуются.
