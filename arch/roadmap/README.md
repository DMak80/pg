# Roadmap (pg)

Здесь — **только несделанные задачи**. Каждая задача исполняется отдельным
проходом dev-flow (spec → plan → код → ревью → мерж в `main`).

## Правила ведения

- **Тег задачи**: `tNN-slug` (например, `t02-per-cluster-secrets`), NN — порядок
  исполнения. На задачу ссылаемся тегом (в коммитах ветки, в spec/plan).
- **Зависимости**: `← tXX-yyy` — задачу можно начинать только после мержа
  указанных. Порядок номеров тегов = порядок исполнения по умолчанию.
- **Мерж-гейт**: задача слита в `main` → её пункт удаляется из этого раздела
  **тем же мерж-коммитом**: и из списка, и из `←`-зависимостей других пунктов.
  Сам, без команды и без вопросов. Никаких пометок «закрыта/реализована» —
  история живёт в git и `docs/superpowers/`.
- Новая задача дописывается в файл своего трека с очередным свободным NN
  (или `t9X-…` для «внеплановых мелочей» — 90–99) и кратким описанием
  результата.
