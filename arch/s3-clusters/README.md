# S3-кластеры хранилища бэкапов — контракт домена

Уровень 2. Контракт etcd S3-домена: контроль-плейн кластеров `/s3/`,
координация воркера `/s3worker/` и клиентский дискавери. Уровень 3 —
разделы контракта (`01`–`09`); исполнительная сторона —
[s3worker/README.md](../s3worker/README.md).

## 1. Назначение домена

**Пул S3-серверов хранилища бэкапов с гео-распределением** (привязка нод к
docker/swarm-хостам) и mesh-репликацией между нодами. Потребитель —
подсистема бэкапов ([backups/README.md](../backups/README.md)); для клиентов пул —
обычный S3 ([07-client-pool.md](07-client-pool.md)).

**Разделение ответственности**: панель AdminPanel **декларирует** кластеры
через HTTP API воркера, **S3Worker исполняет**
([s3worker/README.md](../s3worker/README.md)); в etcd домена пишет только
воркер. PgWorker — клиент пула (читатель `endpoints`), участником контракта
не является.

## 2. Имена

- **Кластер `<C>`** — `^[a-z][a-z0-9_]{0,62}$` (как pg/kafka/valkey; без
  дефиса).
- **Инстанс `<I>`** — уникальное произвольное имя того же паттерна (задаёт
  панель; генерация `node<k>` НЕ используется), ≤ 9 на кластер.
- Кластер может иметь **0 и более инстансов** (декларация без развёртывания
  валидна).
- Имя инстанса = ключ etcd (`nodes/<I>/…`) = имя docker-объектов
  (`s3w-<C>-<I>…`, [s3worker/01-placement.md](../s3worker/01-placement.md) §2)
  = имя target/коммуникации репликации (`TargetRecord.Name`,
  [owns3/07-replication.md](../../../OwnS3/arch/owns3/07-replication.md) §2).
- Имя `orchestrator` зарезервировано (сертификат оркестратора PKI,
  [06-secrets.md](06-secrets.md) §2).

## 4. Свойства, на которые опираются все разделы

- **Один общий etcd-контур** установки ([17-synchronization-principles.md](../17-synchronization-principles.md) S1);
  динамика покрывается тиками воркера (5 с) и панели (3 с) — watch не
  используется ([01-transport.md](01-transport.md) §1).
- **Декларативная модель**: отсутствие `config.state` = Active-кластер;
  `NOT_INITIALIZED`/`TO_REMOVE` — заявки панели
  ([02-keys.md](02-keys.md) §1).
- **Толерантность парсеров**: неизвестные ключи и новые поля JSON не ломают
  чтение ([02-keys.md](02-keys.md) §3, [09-panel.md](09-panel.md) §2).
- **Единственный писатель** `/s3/` и `/s3worker/` — S3Worker; исключение —
  серверный серт API `/workers/api_tls/s3worker` (пишет панель,
  [08-coordination.md](08-coordination.md) §2).
- **Гарантии — от реплицированных источников**: etcd (декларации и
  координация) и mesh-репликация; локальный volume инстанса копией не
  является ([05-platform.md](05-platform.md) §2).
