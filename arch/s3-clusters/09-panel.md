# S3-кластеры: панель (проекция)

Уровень 3. Что панель AdminPanel читает из домена и как мутирует. Ключи —
[02-keys.md](02-keys.md), координация — [08-coordination.md](08-coordination.md).

## 1. Чтение и мутации

- Панель читает `/s3/` (декларации, факт, наблюдение) и
  `/s3worker/{api,rotations}/`; в etcd домена S3 **не пишет ничего**.
- Мутации (создание/удаление кластера, состав инстансов, ресурсы, `links`,
  deny/allow, ротации, синхронный зонд) — **только через HTTP API S3Worker**
  ([s3worker/07-api.md](../s3worker/07-api.md)); проекция —
  [adminpanel/02-etcd-contract.md](../adminpanel/02-etcd-contract.md) §12.

## 2. Совместимость с механикой панели

- **unknownKeys-толерантность**: неизвестные ключи и поля не ломают тик
  ([02-keys.md](02-keys.md) §3).
- **Битый JSON** — parseError-запись без падения тика.
- **`state`-семантика** «отсутствие = Active» ([02-keys.md](02-keys.md) §1).
