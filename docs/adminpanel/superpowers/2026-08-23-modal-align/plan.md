# Plan: Выравнивание ряда «Бакеты / Шарды / Реплики» (modal-align)

Спека: `spec.md` (тот же каталог). Микро-фикс: один шаг кода + финальный коммит.

## Шаг 1. Description-заглушки для «Бакетов» и «Шардов»

- **Вход:** `frontend/src/pages/clusters/ClusterCreateModal.tsx`, ряд `Group grow gap="sm"` (строки ~86–94): NumberInput «Бакеты» и «Шарды» без description, «Реплики» — с `description="2 = мастер + реплика"`.
- **Действие:** добавить в NumberInput «Бакеты» и «Шарды» prop `description={'\u00A0'}` (неразрывный пробел — непустая строка, чтобы Mantine отрендерил блок description). Больше ничего не менять: валидация, error-пропы, остальные поля и ряд ресурсов — как есть.
- **Выход:** все три поля ряда имеют description-блок; у «Бакетов» и «Шардов» он визуально пуст, но той же типографики/высоты (size sm, dimmed), что у «Реплик» — ряд выровнен по высоте.
- **Проверка:** `cd frontend && npm run build` — tsc и vite зелёные; визуально — открыть модалку «Создать кластер», убедиться, что три поля ряда одной высоты и их нижние кромки совпадают.
