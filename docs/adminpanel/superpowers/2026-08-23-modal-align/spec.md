# Spec: Выравнивание ряда «Бакеты / Шарды / Реплики» в модалке создания кластера

Дата: 2026-08-23 · Worktree: `fix-modal-align` · Scope: только `frontend/src/pages/clusters/ClusterCreateModal.tsx`

## Цель

В модалке создания кластера (вкладка «Кластеры» → кнопка «Создать кластер») ряд из трёх NumberInput — «Бакеты», «Шарды», «Реплики» — визуально не выровнен: у «Реплик» есть description «2 = мастер + реплика», из-за чего это поле выше двух соседних (подтверждено скриншотом пользователя). Требование пользователя: под «Бакетами» и «Шардами» оставить пустое место той же высоты, чтобы все три элемента ряда были выровнены.

## Решение (принято автономно, бланкетный апрув)

Добавить NumberInput «Бакеты» и «Шарды» prop `description={'\u00A0'}` (неразрывный пробел). Mantine рендерит description-строку той же типографики и высоты (size sm, dimmed), что и у «Реплик»: заглушка визуально пуста, но резервирует идентичную высоту — поля ряда выравниваются без CSS-хаков и изменений раскладки. Допустимая альтернатива — константа-заглушка (например, `const NBSP = '\u00A0'`); выбран инлайн-вариант как минимальный дифф в двух строках.

Не меняется: клиентская валидация, error-слоты (error и так рендерится на своём месте после description), остальные поля (имя, ряд ресурсов), логика формы и мутация. Контракт API не затрагивается — чисто визуальный фикс одного файла.

## Критерии приёмки

- Три поля ряда «Бакеты / Шарды / Реплики» визуально одной высоты и выровнены; под «Бакетами» и «Шардами» — пустая заглушка той же высоты, что description «Реплик».
- `cd frontend && npm run build` зелёный (tsc + vite).
- Поведение и логика формы не изменены (дифф — только два prop-заглушки description).
